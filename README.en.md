This project is a Python-based API automation testing framework designed for automated testing of web interfaces. The framework integrates commonly used testing libraries such as `pytest` and `allure`, and encapsulates modules for logging, assertions, YAML file reading, and interface requests, aiming to improve the maintainability and readability of test scripts.

---

## 📌 Main Functional Modules

- **core**: Provides core interface request functionality, encapsulating the `RestClient` class for sending HTTP requests.
- **utils**: Utility module containing the assertion tool `AssertUtil`, YAML file reading tool `YamlUtil`, and logging tool `Logger`.
